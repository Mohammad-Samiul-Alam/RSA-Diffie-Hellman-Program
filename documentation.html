RSA & Diffie-Hellman

Short definitions, input, Python code, and sample output.

1. RSA Algorithm

Short definition: RSA is a public-key cryptography algorithm used to encrypt and decrypt data using a public key and a private key.

Input

p = 47, q = 71, e = 79, message = 6882326879666683

Code

# RSA Algorithm
p = 47                                   # First prime number
q = 71                                   # Second prime number
n = p * q                                # Modulus = 3337
phi = (p - 1) * (q - 1)                  # Euler's totient = 3220
e = 79                                   # Public exponent
d = pow(e, -1, phi)                      # Private exponent

message = "6882326879666683"             # Original message
padding = (-len(message)) % 3            # Number of zeros needed
padded = message + "0" * padding         # Add zeros to make 3-digit blocks
blocks = [int(padded[i:i+3]) for i in range(0, len(padded), 3)]  # Split message

encrypted = [pow(m, e, n) for m in blocks]   # Encrypt: C = M^e mod n
decrypted = [pow(c, d, n) for c in encrypted] # Decrypt: M = C^d mod n

result = "".join(f"{m:03d}" for m in decrypted)  # Join decrypted blocks
result = result[:-padding] if padding else result # Remove added zeros

print("Original blocks:", blocks)         # Display input blocks
print("Encrypted blocks:", encrypted)     # Display encrypted blocks
print("Decrypted blocks:", decrypted)     # Display decrypted blocks
print("Original message:", result)        # Display recovered message

Sample output

Original blocks: [688, 232, 687, 966, 668, 300]
Encrypted blocks: [1570, 2756, 2091, 2276, 2423, 3126]
Decrypted blocks: [688, 232, 687, 966, 668, 300]
Original message: 6882326879666683

Remember: Encryption: C = Me mod n. Decryption: M = Cd mod n.

2. Diffie-Hellman Key Exchange

Short definition: Diffie-Hellman is a key exchange method that allows two people to create the same secret key over a public channel.

Input

p = 353, g = 3, Alice's private key a = 97, Bob's private key b = 233

Code

# Diffie-Hellman Key Exchange
p = 353                       # Public prime number
g = 3                         # Public primitive root
a = 97                        # Alice's private key
b = 233                       # Bob's private key

A = pow(g, a, p)              # Alice's public key
B = pow(g, b, p)              # Bob's public key

alice_key = pow(B, a, p)      # Alice calculates shared key
bob_key = pow(A, b, p)        # Bob calculates shared key

print("Alice Public Key:", A)         # Display Alice's public key
print("Bob Public Key:", B)           # Display Bob's public key
print("Alice Shared Key:", alice_key) # Display Alice's shared key
print("Bob Shared Key:", bob_key)     # Display Bob's shared key

if alice_key == bob_key:              # Check whether keys match
    print("Key Exchange Successful!") # Both keys are equal
else:
    print("Key Exchange Failed!")     # Keys are not equal

Sample output

Alice Public Key: 40
Bob Public Key: 248
Alice Shared Key: 160
Bob Shared Key: 160
Key Exchange Successful!

Remember: Alice's shared key = Ba mod p. Bob's shared key = Ab mod p. Both keys must be equal.

Note: These are small educational examples for learning. Do not use these example keys or textbook RSA directly for real-world security.
